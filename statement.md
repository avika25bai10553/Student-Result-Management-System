# Project Statement

## Project Title

Student Result Management System

## Problem Statement

Managing student academic records manually can be time-consuming and may lead to errors while storing, searching, and calculating student results.

The Student Result Management System is developed as a Java-based console application to organize student details, course information, and academic results in a structured manner.

## Project Scope

The project focuses on managing basic academic information through a simple menu-driven Java application.

The system provides functionalities for:

- Managing student records
- Managing course records
- Entering student marks
- Viewing student results
- Searching student and course information
- Calculating average marks
- Calculating grades
- Validating user input

## Target Users

The intended users of this system are:

- Students for viewing academic result information
- Faculty members for managing student and course results
- Academic staff for maintaining basic student result records

## High-Level Features

### Student Management

- Add student details
- View all students
- Search students using Student ID
- Delete student records

### Course Management

- Add course details
- View available courses
- Search courses using Course Code

### Result Management

- Enter marks for students
- View student results
- Calculate average marks
- Calculate grades automatically

### Validation and Error Handling

- Validate user inputs
- Check marks within the valid range
- Prevent duplicate Student IDs
- Prevent duplicate Course Codes
- Handle invalid inputs using exception handling

## Technology Used

- Java
- Object-Oriented Programming
- ArrayList
- File Handling
- Exception Handling
- Git and GitHub

## Expected Outcome

The expected outcome of the project is a functional Java console application that provides an organized way to manage student, course, and result information while demonstrating important Java programming concepts.
